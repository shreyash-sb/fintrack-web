# 💰 Smart Expense Manager

A modern and responsive Expense Tracker Web Application that helps users manage their income, track expenses, and maintain personal budgets efficiently.

## 🚀 Features
- Add, edit, and delete income and expense transactions  
- Categorize expenses (Food, Travel, Shopping, Bills, etc.)  
- Date-wise transaction tracking  
- Real-time balance calculation (Income - Expense)  
- Transaction history view with filters  
- Fully responsive UI for mobile and desktop  
- Data persistence using LocalStorage / optional database integration  

## 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript / React  
Styling: Tailwind CSS / Bootstrap (optional)  
Backend (optional): Node.js + Express  
Database (optional): MongoDB / Firebase / LocalStorage
